درباره سایت نمونه

سایت نمونه یک وب‌سایت آموزشی است که برای تمرین مهارت‌های توسعه وب و کار با Git ساخته شده است. تمام صفحات این سایت با HTML، CSS و JavaScript پیاده‌سازی شده‌اند و داده‌ها در مرورگر کاربر ذخیره می‌شوند.

هدف ما انتشار مقالات آموزشی ساده و کاربردی در زمینه‌های برنامه‌نویسی، پایگاه داده، شبکه و امنیت است. این پروژه به عنوان مثال کلاسی Git ساخته شده تا مراحل ساخت یک وب‌سایت و مدیریت آن با شاخه‌ها (Branch) و درخواست کشش (Pull Request) را نشان دهد.
